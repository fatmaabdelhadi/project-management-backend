# Focus Hive – Project Management Platform (Backend)

Backend API for **Focus Hive**, a MERN-based project management platform that enables teams to manage projects, tasks, and dependencies while tracking team progress.

## Setup

To run the project correctly after cloning the repo, install these dependencies in your project terminal:
> npm install -g yarn
> 
If the previous command doesn't work, open **PowerShell as administrator** and run:
>
> Set-ExecutionPolicy RemoteSigned
>
Then retry installing yarn and run:
>
> yarn add express mongoose dotenv nodemon --save
>
## Tech Stack
Node.js • Express.js • MongoDB • Mongoose • REST API

## Overview
The backend provides API endpoints for:

- Project and task management  
- Task dependency tracking  
- User authentication and role-based access  
- Data persistence using MongoDB

This repository contains the **Node.js / Express backend** for the Focus Hive platform.
